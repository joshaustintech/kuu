# Phases 11-12

## Phase 11: CLI And Standalone Lua

Goal:
Match the standalone behavior needed by `main.lua` and manual section 7.

Subtask 11.1 prompt:
```text
Implement the Kuu CLI with Lua-compatible script execution, arg table, -e chunks, -l module loading, -i interactive placeholder, stdin execution, and exit codes.
```

Done when:

- script execution works
- `arg` behavior is tested
- `-e` and stdin execution are tested

Subtask 11.2 prompt:
```text
Implement a minimal Lua-compatible REPL using std::io. Support expression shorthand where required and preserve globals across inputs.
```

Done when:

- REPL smoke tests pass through stdin-driven integration tests

## Phase 12: Full Conformance Loop

Goal:
Close the gap from selected fixtures to the full local suite.

Subtask 12.1 prompt:
```text
Build a test runner command that executes each local Lua 5.5 test file under Kuu, records pass/fail/unsupported, captures logs, and writes a deterministic conformance report.
```

Done when:

- runner handles pass, fail, timeout, and unsupported cases

Subtask 12.2 prompt:
```text
Iteratively fix failures until every pure Lua portion of the local Lua 5.5 suite passes. Add a minimized failing regression test before each fix.
```

Done when:

- all supported upstream tests pass
- each fix starts from a failing regression fixture

Subtask 12.3 prompt:
```text
Evaluate api.lua and C-library-dependent attrib.lua checks. Implement a Rust-native T shim where behavior can be reproduced safely. Mark truly C-ABI and dynamic-library requirements unsupported with exact reasons.
```

Done when:

- every unsupported item has a precise reason
- the conformance report separates language failures from excluded C-ABI behavior
